# Методический конструктор курса «Для беременных»

Адаптивная HTML-страница-справочник для кураторов курса. Внутри: вводный блок и все пять недель курса, разложенные по дням, темам и методическим карточкам.

## Запуск

Откройте `index.html` в браузере. Страница не требует сборки, сервера или внешних библиотек.

## Возможности

- быстрый поиск по методическим карточкам;
- навигация по пяти неделям и дням каждой недели;
- каталог категорий и фильтрация по темам и тегам;
- быстрый поиск по цели, фокусу и действиям куратора;
- ссылки на исходные Google Docs, Kinescope, памятки, меню и материалы курса;
- отдельная «красная линия» с границами компетенций куратора;
- без прогресса и отметок «изучено»: это рабочий справочник, а не учебный трекер.

## Источники

- Google Docs: «Вводная + 1 неделя Беременные»;
- Google Docs: «Бриф Беременные26»;
- Google Docs: «2 неделя беременные 2026», «3 неделя беременные 2026», «4 неделя беременные 2026», «5 неделя беременные 2026».

Контент предназначен для методической навигации кураторов и не заменяет медицинские рекомендации специалистов.
